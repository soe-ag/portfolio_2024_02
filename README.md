# Portfolio 2024

Personal portfolio showcasing projects, work experience, and development skills.

## Stack

- **[Nuxt 3](https://nuxt.com)** + **[Vue 3](https://vuejs.org/)** + **[TypeScript](https://www.typescriptlang.org/)**
- **[UnoCSS](https://unocss.dev)** — atomic CSS with icon & web-font presets
- **[PrimeVue 4](https://primevue.org)** — UI components (Aura theme)
- **[@nuxt/image](https://image.nuxt.com)** — image optimization
- **[@nuxtjs/color-mode](https://color-mode.nuxtjs.org/)** — dark / light mode

## Getting Started

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run lint     # lint
```

## Structure

```
pages/       # Home, About, Works, Others
components/  # Reusable UI components
layouts/     # Shared page layouts
utils/       # Data & constants
assets/      # Global styles
```
